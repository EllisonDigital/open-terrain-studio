# Presets

Example projects (the v0.2 reference landforms: alpine range, canyon, dune field, and later ones) live in
`app/examples/` so the packaged app can open them from *File → Open Example*.

Species presets (YAML) for the Trees, Shrubs, Grass and Debris / Rocks nodes live in `app/examples/species/`,
for the same reason: the app lists them in each vegetation node's settings. See `docs/vegetation.md`.

Graph templates arrive in v0.8. See `docs/ROADMAP.md`.
